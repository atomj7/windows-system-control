# Helios

Локальная служба для Windows: находит компоненты компьютера, показывает температуру и остальные метрики, задаёт цвет подсветки и скорость вентиляторов там, где протокол известен и безопасен.

Язык движка — C++20. HID, WMI, DXGI и NVML живут в отдельном процессе `helios.exe --worker`. Окно Helios этот код не вызывает: если драйвер NVIDIA или DXGI падает с `0xC0000005`, закрывается только модуль железа, окно остаётся и запускает модуль снова. Снимок устройств — `data/live.json`, команды цвета и вентиляторов — `data/commands`.

На этой машине (Linux) Helios работает как стенд: плата, процессор, видеокарта, СЖО, память, вентиляторы и накопитель с живой физикой. На Windows тот же интерфейс читает реальное железо.

## Что реально управляется

| Устройство | Цвет | Вентиляторы |
| --- | --- | --- |
| NZXT Kraken / Hue 2 по HID | да, отчёт 64 байта | да, каналы контроллера |
| NVIDIA через NVML | — | да, если драйвер отдаёт `SetFanSpeed`. RPM читается через `nvmlFanSpeedInfo_t`, не через устаревшую тройку аргументов — иначе NVML падает с `0xC0000005` на каждом опросе |
| Устройства в OpenRGB (порт 6742) | да: рукопожатие протокола, режим Direct, затем цвет кнопкой «Применить» | как решит OpenRGB |
| Gigabyte RGB Fusion 2.0 (ITE 048D:8297 / 5702) | да, HID-отчёт как в OpenRGB | SuperIO-крыльчатки платы — нет, только PawnIO+карта чипа |
| Corsair, Lian Li, MSI, прочий Super I/O | видны по VID/PID или WMI | только в профиле, пакеты не отправляются |
| Корпусной хаб с ИК-пультом без USB | нет | нет: Helios не принимает инфракрасный пульт и не видит устройство, которого нет на USB |

Helios не ставит WinRing0 и не пишет регистры Super I/O. PawnIO ищется по устройству `\Device\PawnIO`, по службе Windows, по файлам в Program Files и по реестру — не только по старому пути `\\.\PawnIO`. Если драйвер стоит, в **Драйверы** он будет «Готов» или «Недоступен». `ACCESS_DENIED` значит: Helios видит PawnIO, Windows не даёт открыть устройство. В листе драйверов есть кнопка **Запустить от администратора** — Helios перезапустится через UAC, и модуль железа унаследует повышенный токен. Либо в установщике PawnIO 2.2 включи доступ для всех пользователей. Даже после успешного открытия SuperIO Helios пока только читает наличие драйвера: карту чипа платы ещё не пишет. Непроверенные USB-протоколы помечаются как «в профиле»: цвет и кривая сохраняются, на шину ничего не уходит.

Первый запуск создаёт профили «Тихий» и «Нагрузка» и не применяет их. Вентиляторы реальных устройств стартуют в режиме «Авто», пока ты сам не выберешь кривую или ручной процент. Ниже порога скважности крыльчатка не останавливается, если не включено «Разрешить остановку».

## Запуск стенда

Нужны CMake, g++ с C++20 и Node.js 20+.

```bash
./scripts/build.sh
./build/helios --port 47621
```

Открой http://127.0.0.1:47621 . На Linux режим стенда включается сам. `--hardware` на Linux ничего не переключает на реальное железо: платформенный код Windows в эту сборку не входит.

## Установка на Windows

Самый простой путь — установщик, без Visual Studio и Node.

1. Скачай `Helios-Setup.exe` из репозитория (`installer/Helios-Setup.exe`) или zip `pack/Helios-windows.zip`.
2. Запусти **Helios-Setup.exe**. Он ставит программу в `%LOCALAPPDATA%\Helios`, ярлыки — в меню Пуск и на рабочий стол.
3. Открой ярлык **Helios**. Появится **окно программы** с тем же интерфейсом, что раньше открывался во вкладке: устройства, иконки, цвет, вентиляторы, графики. Браузер не нужен и вкладку закрывать не надо: закрытие окна останавливает Helios и модуль железа.

Если окна нет, смотри `%LOCALAPPDATA%\Helios\helios.log`. Если окно есть, а список устройств пуст — `%LOCALAPPDATA%\Helios\helios-worker.log`.

Нужен **Microsoft Edge WebView2 Runtime** (на Windows 11 и на большинстве машин с Edge он уже стоит). Если окно тёмное и просит WebView2 — поставь runtime и открой Helios снова.

После обновления закрой Helios и поставь новый `Helios-Setup.exe` поверх старого. Установщик сам завершает старый `helios.exe`.

Windows может спросить про неизвестное приложение: установщик не подписан сертификатом. Нажми «Подробнее» → «Выполнить в любом случае».

Удаление: Параметры Windows → Приложения → Helios, либо `Uninstall.exe` в папке установки.

Портативный вариант: распакуй `Helios-windows.zip` и запусти `install.cmd` или сразу `Helios.cmd`.

## Сборка на Windows

`scripts/build.sh` — это bash для Linux. В PowerShell он ничего не собирает. Нужен `.\scripts\build.ps1`. Если нужен только запуск, сборка не нужна — бери установщик выше.

Поставь:

1. [Node.js LTS](https://nodejs.org/en/download)
2. [CMake](https://cmake.org/download/) (галка Add CMake to PATH)
3. [Visual Studio 2022 Community](https://visualstudio.microsoft.com/vs/community/) с нагрузкой **Разработка классических приложений на C++**

Закрой и открой PowerShell, затем из корня репозитория:

```powershell
cd D:\myProjects\windows-system-control
.\scripts\build.ps1
.\scripts\run.ps1
```

Либо вручную:

```powershell
cd ui
npm install
npm run build
cd ..
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
.\build\Release\helios.exe --hardware
```

Открой http://127.0.0.1:47621 . Стенд без железа: `.\build\Release\helios.exe --simulate`.

Если распаковал zip (`windows-system-control-main`), команды те же из этой папки. Логи Cursor (`AgentHostUpdater`, `ENOPRO`, `punycode`) к Helios не относятся.

Кросс-сборка MinGW с Linux:

```bash
cmake -S . -B build-win -DCMAKE_TOOLCHAIN_FILE=cmake/mingw.cmake
cmake --build build-win -j
```

Интерфейс ищется в `ui/dist` рядом с текущим каталогом или с исполняемым файлом. Сначала `npm run build` в `ui`.

## Флаги

| Флаг | Смысл |
| --- | --- |
| `--port 47621` | HTTP только на 127.0.0.1 |
| `--data data` | профили и последние настройки, `data/store.json` |
| `--simulate` | стенд, без обращений к железу |
| `--hardware` | окно + отдельный процесс обзора SMBIOS, WMI, USB, DXGI, NVML |
| `--worker` | только модуль железа, без окна; окно запускает его само |

Запуск от администратора — кнопка в **Драйверы**, не ярлык. Старый процесс сам закрывается, новый ждёт освобождения порта 47621.

Порт OpenRGB — 6742. RGB планок (JAD/XPG и прочий SMBus) Helios сам не пишет: нужен OpenRGB, запущенный **от администратора**, с SDK Server на 6742, затем «Обзор». Цвет уходит не с карты платы (там только вентиляторы), а с карточки памяти или периферии: выбери цвет и нажми **Применить**. Если RGB Fusion, CAM, iCUE или SignalRGB держат HID, Helios увидит устройство, но запись цвета может не пройти: эти программы забирают интерфейс себе.

## Что спрашивает первый обзор

SMBIOS (плата и прошивка), WMI (процессор, диски, память, зоны ACPI), USB и HID, DXGI и NVML, наличие ADL и PawnIO. Шаги видны на стартовом экране. Повторный обзор — кнопка «Обзор».

Графики копят около 20 минут и отдают на экран ужатый ряд. Вкладки: температура, загрузка, обороты, мощность, частоты.
