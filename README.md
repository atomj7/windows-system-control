# Helios

Локальная служба для Windows: находит компоненты компьютера, показывает температуру и остальные метрики, задаёт цвет подсветки и скорость вентиляторов там, где протокол известен и безопасен.

Язык движка — C++20. Ему нужен прямой доступ к HID, WMI, DXGI и NVML, и он держит одно состояние в памяти без лишней прослойки. Интерфейс — React, его отдаёт тот же процесс на `127.0.0.1`.

На этой машине (Linux) Helios работает как стенд: плата, процессор, видеокарта, СЖО, память, вентиляторы и накопитель с живой физикой. На Windows тот же интерфейс читает реальное железо.

## Что реально управляется

| Устройство | Цвет | Вентиляторы |
| --- | --- | --- |
| NZXT Kraken / Hue 2 по HID | да, отчёт 64 байта | да, каналы контроллера |
| NVIDIA через NVML | — | да, если драйвер отдаёт `SetFanSpeed` |
| Устройства в OpenRGB (порт 6742) | да, протокол SDK | как решит OpenRGB |
| Gigabyte RGB Fusion, Corsair, Lian Li, MSI, Super I/O | видны по VID/PID или WMI | только в профиле, пакеты не отправляются |

Helios не ставит WinRing0 и не пишет регистры Super I/O. PawnIO только обнаруживается: если он установлен, в списке драйверов будет «готов», но служба им не пользуется. Непроверенные USB-протоколы помечаются как «в профиле»: цвет и кривая сохраняются, на шину ничего не уходит.

Первый запуск создаёт профили «Тихий» и «Нагрузка» и не применяет их. Вентиляторы реальных устройств стартуют в режиме «Авто», пока ты сам не выберешь кривую или ручной процент. Ниже порога скважности крыльчатка не останавливается, если не включено «Разрешить остановку».

## Запуск стенда

Нужны CMake, g++ с C++20 и Node.js 20+.

```bash
./scripts/build.sh
./build/helios --port 47621
```

Открой http://127.0.0.1:47621 . На Linux режим стенда включается сам. `--hardware` на Linux ничего не переключает на реальное железо: платформенный код Windows в эту сборку не входит.

## Сборка на Windows

Поставь Visual Studio 2022 (рабочая нагрузка C++), CMake и Node.js. Клонируй репозиторий, например в `D:\myProjects\windows-system-control`, и из корня:

```powershell
.\scripts\build.ps1
.\build\Release\helios.exe --hardware
```

Если CMake положил `helios.exe` прямо в `build\`, запускай его оттуда. Для предпросмотра без железа: `helios.exe --simulate`.

Кросс-сборка MinGW с Linux:

```bash
cmake -S . -B build-win -DCMAKE_TOOLCHAIN_FILE=cmake/mingw.cmake
cmake --build build-win -j
```

Интерфейс ищется в `ui/dist` рядом с текущим каталогом или с исполняемым файлом. Сначала `npm run build` в `ui`.

## Флаги

| Флаг | Смысл |
| --- | --- |
| `--port 47621` | HTTP только на 127.0.0.1 |
| `--data data` | профили и последние настройки, `data/store.json` |
| `--simulate` | стенд, без обращений к железу |
| `--hardware` | обзор SMBIOS, WMI, USB, DXGI, NVML |

Порт OpenRGB — 6742. Если RGB Fusion, CAM, iCUE или SignalRGB держат HID, Helios увидит устройство, но запись цвета может не пройти: эти программы забирают интерфейс себе.

## Что спрашивает первый обзор

SMBIOS (плата и прошивка), WMI (процессор, диски, память, зоны ACPI), USB и HID, DXGI и NVML, наличие ADL и PawnIO. Шаги видны на стартовом экране. Повторный обзор — кнопка «Обзор».

Графики копят около 20 минут и отдают на экран ужатый ряд. Вкладки: температура, загрузка, обороты, мощность, частоты.
